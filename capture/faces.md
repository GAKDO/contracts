# 면별 표준 좌표 (방향·배율)

사진을 펼친 **표준 좌표 이미지**의 방향과 배율입니다. inspect-worker(펼치기·3D 텍스처), capture-server(시점 비교, 부스 탐지 좌표 변환),
web(3D 트윈·핀), 부스 촬영 목록과 폰 윤곽 가이드가 모두 이 표를 따릅니다. (11/2 결정, docs decisions.md)

## 공통 규칙

- 기준 자세: 노트북을 책상에 놓고 사용자가 앞에 앉은 모습. **앞** = 사용자 쪽, **뒤** = 힌지 쪽, **왼쪽·오른쪽** = 앉은 사용자 기준.
- 펼친 이미지는 **그 면을 바깥에서 똑바로 본 모습**이다. 원점은 왼쪽 위, x는 오른쪽, y는 아래.
- 배율은 **1 px = 0.25 mm**(4 px/mm)로 고정한다. 이미지 크기는 기종 치수(`rental.device_model`의 width·depth·base_h·lid_h, mm)에서 정해진다.
  흠집 길이(`lengthMm`)·넓이(`areaMm2`)는 이 배율로 계산한다.
- 원본 사진 좌표(부스 탐지 `PhotoPolygon`)는 사진마다의 호모그래피(`trace.inspect.completed`의 `alignments`)로 이 좌표에 옮긴다.
- 흠집 다각형은 **어디서나 표준 좌표 px**다: 검사 완료 이벤트, REST 응답(`Polygon`), DB `inspection.defect.polygon`. 단위 바꾸기는 없다. mm는 길이·넓이·거리 값에만 쓴다.

## 면별 방향

| 면 | 상태 | 보는 위치 | 이미지 위쪽 | 이미지 왼쪽 | 크기(가로 × 세로) |
|---|---|---|---|---|---|
| TOP 상판 | 닫힘 | 위에서 내려다봄 | 뒤(힌지) | 사용자 왼쪽 | width × depth |
| BOT 바닥 | 닫힘 | 아래에서 올려다봄 | 뒤(힌지) | 사용자 오른쪽 | width × depth |
| SF 앞 옆면 | 닫힘 | 앞에서 | 상판 쪽 | 사용자 왼쪽 | width × (base_h + lid_h) |
| SB 뒤 옆면 | 닫힘 | 뒤에서 | 상판 쪽 | 사용자 오른쪽 | width × (base_h + lid_h) |
| SL 왼쪽 옆면 | 닫힘 | 왼쪽에서 | 상판 쪽 | 뒤(힌지) | depth × (base_h + lid_h) |
| SR 오른쪽 옆면 | 닫힘 | 오른쪽에서 | 상판 쪽 | 앞 | depth × (base_h + lid_h) |
| KB 키보드·팜레스트 | 열림 | 위에서 내려다봄 | 뒤(힌지) | 사용자 왼쪽 | width × depth |
| SCR0·SCR1 화면 | 열림 | 앞에서 | 화면 위 모서리(힌지 반대쪽) | 사용자 왼쪽 | width × depth |

## 촬영할 때

- **BOT은 한 방향으로만 뒤집는다:** 앞 모서리를 들어 뒤로 넘긴다(좌우로 굴리지 않는다). 부스 촬영 목록과 폰 가이드 그림이 이 방향을 보여 준다.
- 윤곽 4점만으로는 180° 돌아간 것과 구분이 안 된다. 펼칠 때는 위 방향과 특징점 보정으로 정한다.
- 폰 윤곽 가이드는 위 표의 "이미지 위쪽"이 화면 위로 오게 그린다.
